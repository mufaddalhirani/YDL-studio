# Changelog

All notable changes to YDL Studio are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses
[semantic versioning](https://semver.org/spec/v2.0.0.html).

## [2.0.0] - 2026-10-27

Rewritten as **YDL Studio**: a packaged Python application with a persistent queue,
settings and history, replacing the single-file prototype it grew out of.

### Added
- Download queue that runs jobs one at a time, with cancel, retry, remove and clear-finished
  controls on every row.
- Batch dialog that parses, previews and de-duplicates a list of pasted links.
- Persistent settings stored in `%APPDATA%\YDL Studio`, validated on load, with a draft
  form that only applies on **Save changes**.
- Download history with search, open, reveal in Explorer, re-download and clear actions.
- Clipboard watching that offers a copied link as a suggestion and never starts it alone.
- System tray with balloon notifications, an in-app toast when the window is visible, and
  an opt-in close-to-tray that keeps downloads running.
- FFmpeg discovery across the app folder, `PATH` and a portable `bin` directory, plus a
  one-click installer that downloads and verifies the official Windows build.
- Subtitles (embedded or sidecar, with language list and auto-generated captions),
  SponsorBlock (mark or remove), playlist item ranges, cookies from an installed browser
  or a `cookies.txt` file, rate limiting, and a free-form field for extra yt-dlp arguments.
- Console page with level-coloured live output, copy, clear and auto-scroll.
- Dark, light and system themes that update on save without a restart.
- Command line entry points: `ydl-studio [URL ...]`, `python -m ydl_studio`,
  `--version` and `--help`.
- Original application icon and window chrome, generated by `scripts/make_icon.py`.
- Test suite covering URL parsing, option mapping, settings persistence, history storage,
  FFmpeg discovery and the download queue, including an offline end-to-end download
  against a local HTTP server.
- Continuous integration: lint and tests on every push and pull request, and a tagged
  release workflow that builds the Windows executable.

### Changed
- Application name, branding and repository layout moved from `yt-dlp-gui` to
  `ydl_studio`, with dependency metadata in `pyproject.toml`.

### Removed
- The bundled browser extension and the copied Linux package tree from the original
  release archive; neither was functional in this project.

## [1.0.0]

The original single-window `yt-dlp-gui` prototype: one URL at a time, options held in
memory, no queue, history or tray.
